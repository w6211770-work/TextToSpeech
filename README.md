# 英日読み上げアプリ

英語と日本語の文章を交互に読み上げるPWAです。

## 概要

英語学習向けの読み上げアプリです。

テキストファイルを読み込み、英語は英語音声、日本語は日本語音声で読み上げます。

## 機能

- テキストファイル読込
- 英語音声読み上げ
- 日本語音声読み上げ
- 開始/停止ボタン
- PWA対応
- スマホ対応

## 使用方法

1. テキストファイルを選択
2. 開始ボタンを押す
3. 文章を順番に読み上げ

## サンプル

Hello.

こんにちは。

How are you?

元気ですか？
