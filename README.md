# TextToSpeech

英語と日本語の文章を読み上げる PWA（Progressive Web App）です。

テキストファイルを読み込み、英語行は英語音声、日本語行は日本語音声で順番に読み上げます。

スマートフォンへのインストールにも対応しており、英語学習や音読練習に利用できます。

---

## 主な機能

- テキストファイル読込
- 英語音声読み上げ
- 日本語音声読み上げ
- 開始／停止ボタン
- PWA対応
- スマートフォン対応
- Web Speech API 利用

---

## 使用方法

### 1. テキストファイルを準備

例

```text
Hello.

こんにちは。

How are you?

元気ですか？
```

### 2. ファイルを選択

「ファイルを選択」ボタンからテキストファイルを読み込みます。

### 3. 読み上げ開始

「開始」ボタンを押すと、テキストを上から順番に読み上げます。

### 4. 停止

「停止」ボタンで読み上げを停止できます。
